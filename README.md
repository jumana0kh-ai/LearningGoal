# Learning Tracker

Learning Tracker is an iOS app that helps you set a learning goal, log the days you practiced, and see your progress over time.

## Main Features

- **Set a learning goal** — Choose what you want to learn and give yourself a week, a month, or a year.
- **Log your learning** — Tap **Log as Learned** when you’ve practiced for the day.
- **Use a freeze day** — Take a planned day off and track it separately from your learning days.
- **Review your activity** — See your week at a glance and check how many days you learned or froze.

## Built With

- **Swift** for the app logic
- **SwiftUI** for the interface
- **MVVM** to organize the models, views, and app state
